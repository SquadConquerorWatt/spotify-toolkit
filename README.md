# 🎵 Spotify

**Music client toolkit. Unlock features. Remove ads.**
Modification toolkit for Spotify. It removes ads, unlocks high-quality audio, enables unlimited skips, and unlocks offline mode — without a subscription.
✨ Features

    🚫 Ad-free listening — remove all audio and banner ads

    🎚️ High-quality audio — unlock 320kbps

    ⏭️ Unlimited skips — skip any track

    📥 Offline mode — download tracks for offline

    💸 No subscription — works with free accounts

    🖥️ Cross-platform — Windows, macOS, Linux

    🔄 Auto-update — patches new Spotify versions

    🔓 Open source — audit the code yourself
